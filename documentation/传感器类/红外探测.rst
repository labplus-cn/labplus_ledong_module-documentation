红外探测
===================

.. figure:: /static/图片/红外探测.png
	:width: 55%
	:align: center

概述
--------------------
探测测距传感器，检测正前方是否有障碍物。

技术参数
-------------------

工作电压： VCC 3.3V -5V

模块尺寸：24*48mm

固定安装：2个兼容塑料积木通孔

数据类型：模拟采样值

探测距离：0-5cm


引脚定义
-------------------

=====  ======== 
引脚    定义   
=====  ========  
GND    地  
VCC    电源  
AO     模拟采样值
NC     空
=====  ========
