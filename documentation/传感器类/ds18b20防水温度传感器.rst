温度传感器(DS18B20)
=====================

.. figure:: /static/图片/ds18b20.png
	:width: 55%
	:align: center

概述
--------------------
基于DS18B20数字温度传感器,用于检测环境温度。


技术参数
-------------------

工作电压： VCC 3.3V -5V

模块尺寸：24*48mm

固定安装：2个兼容塑料积木通孔

温度：-55--125℃



引脚定义
-------------------

=====  ======== 
引脚    定义   
=====  ========  
GND    地  
VCC    电源  
DI     数字输出
NC     空
=====  ========
