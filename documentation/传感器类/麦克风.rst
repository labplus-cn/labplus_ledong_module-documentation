声音传感器
===================

.. figure:: /static/图片/声音-H.png
	:width: 55%
	:align: center

概述
--------------------
该模块是将声音信号转化为电信号，可用于测量环境音量等应用。

技术参数
-------------------

工作电压： VCC 3.3V -5V

模块尺寸：24*48mm

固定安装：2个兼容乐高积木通孔

数据类型：模拟采样值



引脚定义
-------------------

=====  ======== 
引脚    定义   
=====  ========  
GND    地  
VCC    电源  
AO     模拟采样值
NC     空
=====  ========
